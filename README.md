# Mesa — menú semanal visual

Aplicación web para organizar comidas y cenas de forma visual. La lista de la compra se genera automáticamente a partir de los ingredientes de cada plato y conserva el progreso en el navegador.

## Cómo probarla

Abre `index.html` en un navegador moderno. No requiere instalación ni servidor.

## Funciones incluidas

- Vista semanal de comidas y cenas, adaptable a móvil.
- Recetario de platos habituales con búsqueda.
- Platos personalizados.
- Navegación entre semanas y notas semanales.
- Lista de la compra agrupada por secciones.
- Progreso de compra, copia al portapapeles y persistencia local.

## Siguiente evolución

La estructura está preparada para sustituir el almacenamiento local por una API y una base de datos cuando se quiera sincronizar el menú y la compra entre varios dispositivos.
